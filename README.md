# CET6 成绩查询演示页面

仿中国教育考试网（NEEA）官方风格的 CET6 成绩查询演示页面，纯前端单文件实现。

## ✨ 特性

- 🎨 **官方视觉**：完整复刻 NEEA 冷色调（深蓝 `#003F88` + 浅蓝 `#E8F2FB` + 红色 `#D9534F`）
- 📱 **响应式**：PC（≤1200px 居中）+ 移动端（≤768px 单列堆叠）自适应
- 🔐 **登录界面**：账号密码任填（不校验），自动校验验证码
- 🎲 **随机数据**：每次登录随机生成 16 位准考证号 / 报告单编号；听力/阅读/写作翻译在 130-150 区间随机，总分 ≤ 424
- 🪶 **零依赖**：单 HTML 文件，CSS/JS 全部内联，无任何外部依赖
- 🌍 **公网访问**：已启用 GitHub Pages，所有人可访问

## 🚀 在线访问

GitHub Pages 地址：
```
https://<your-github-username>.github.io/cet6-score-page/
```

## 🛠 本地预览

直接双击 `index.html` 即可在浏览器打开，无需任何构建步骤。

### 使用步骤

1. 打开页面 → 输入**任意账号** + **任意密码**
2. 输入验证码（点击图片或"换一张"可刷新）
3. 点击"登录" → 自动跳转到成绩页
4. 每次登录都会看到**不同**的随机成绩

## 🎯 关键规则

| 项 | 规则 |
|----|------|
| 登录校验 | 不校验账号密码，仅校验非空 + 验证码 |
| 证件号码 | 保留用户登录时输入的内容 |
| 姓名/学校 | 不显示（按需求移除）|
| 准考证号 | 每次登录随机生成 16 位数字 |
| 报告单编号 | 每次登录随机生成 16 位数字 |
| 听力/阅读/写作翻译 | 每次登录随机生成 130-150 整数 |
| 总分 | 三项之和，且 ≤ 424 |
| 字号 | 14px（与标签一致，红色仅靠颜色区分总分）|
| 对齐 | 所有数值贴右对齐 |

## 🛡 编码兼容性

- ✅ HTML 头部声明 `<meta charset="UTF-8">`
- ✅ 文件保存为 UTF-8（无 BOM）
- ✅ `<meta http-equiv="X-UA-Compatible" content="IE=edge">` 兼容老 IE
- ✅ `format-detection=no` 防止移动端号码被误标为电话
- ✅ 内联 SVG favicon（避免 404 警告）
